# Pre-rendered Home animation

Six-second GIF loops, rendered from the existing SVG artwork with Sharp and encoded with Pillow. Banner: 960px wide; learning and connection: 400px wide; circuit: 280px wide. A shared 128-color palette limits size and palette flicker. Still PNGs are used off-screen, for hidden documents, and with reduced-motion settings.

Banner moves its curves; Learn propagates wavefront brightness radially; Build pulses circuit connections and gates; Connect breathes in brightness. Icon hover colors use the original luminous-hero.png.

These replace live banner SVG filters/transforms. GIF decoding still has a cost; actual playback performance should be checked on the target device.
