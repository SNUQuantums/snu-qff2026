# Pre-rendered Home animation

Pre-rendered GIF loops, rendered from the existing SVG artwork with Sharp and encoded with Pillow. Banner: 960px wide; learning and connection: 400px wide; circuit: 280px wide. A shared palette limits size and palette flicker. Still PNGs are used off-screen, for hidden documents, and with reduced-motion settings.

Banner uses the selected Flowing wave candidate: 72 frames, 7.2 seconds, 192 colors, with phase-offset independent strand motion; Learn propagates wavefront brightness radially; Build pulses circuit connections and gates; Connect breathes in brightness. Icon hover colors use the original luminous-hero.png.

These replace live banner SVG filters/transforms. GIF decoding still has a cost; actual playback performance should be checked on the target device.
